# 우수생 평가 계산기

운영매니저를 위한 향상도 · 평가평균 · 출결 점수 자동 계산 웹앱입니다.

## 사용 방법

👉 **[웹앱 바로 열기](https://[아이디].github.io/excellence-evaluator/ )**

1. 출석률.xlsx 파일과 우수학습자 평가.xlsx 파일을 준비합니다
2. 위 링크에서 두 파일을 업로드합니다
3. 계산 실행 버튼을 누르면 자동으로 점수가 산출됩니다

## 파일 형식

- **출석률.xlsx**: 날짜별 시트, 이름/입실시간/중간출석시간/퇴실시간 컬럼 필요
- **우수학습자 평가.xlsx**: 성함, 입과 평가, 1차~수료 평가 컬럼 필요

## 향상도 산출 방식

| 방식 | 산식 |
|------|------|
| 기존 | (최종점수 − 입과) ÷ (100 − 입과) × 10 |
| 가중점수 기반 | (가중점수 − 입과) ÷ (100 − 입과) × 10 |

가중점수 = (1차×0.2 + 2차×0.3 + 3차×0.5 + 수료×1.0) ÷ 가중치합
