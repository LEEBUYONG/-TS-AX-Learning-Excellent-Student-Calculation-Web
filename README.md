# 우수생 평가 계산기

운영매니저를 위한 **향상도 · 평가평균 · 출결 점수 자동 계산 웹앱**입니다.

👉 **[웹앱 바로 열기](https://leebuyong.github.io/-TS-AX-Learning-Excellent-Student-Calculation-Web/)**

---

## 주요 기능

- `출석률.xlsx`, `우수학습자 평가.xlsx` 업로드
- 향상도, 평가평균, 출결 점수 자동 계산
- 오전 / 중간 / 퇴실 출결 각각 반영
- 기수별 출석 시간 기준 설정 가능
- 기존 향상도와 가중점수 기반 향상도 비교 가능

---

## 사용 방법

1. `출석률.xlsx`, `우수학습자 평가.xlsx` 파일을 준비합니다.
2. 웹앱에 두 파일을 업로드합니다.
3. 출석 시간 기준을 현재 기수에 맞게 확인합니다.
4. 계산 결과를 확인한 뒤 우수생 평가표에 반영합니다.

## 계산 기준

| 항목 | 배점 | 기준 |
|---|---:|---|
| 향상도 | 10점 | 입과 평가 대비 향상 정도 |
| 평가 평균 | 20점 | 전체 시험 평균을 20점 만점으로 환산 |
| 출결 | 20점 | 결석, 지각 기준으로 감점 |

---

## 향상도 계산

| 방식 | 산식 |
|---|---|
| 기존 방식 | `(최종점수 - 입과평가) ÷ (100 - 입과평가) × 10` |
| 가중점수 기반 | `(가중점수 - 입과평가) ÷ (100 - 입과평가) × 10` |

```text
가중점수 = (1차×0.2 + 2차×0.3 + 3차×0.5 + 수료×1.0) ÷ 실제 응시한 시험의 가중치 합
```

- 수료 평가가 없으면 수료 점수와 가중치는 제외합니다.
- 향상도는 최종적으로 0점~10점 사이로 보정됩니다.
- 입과 평가가 100점인 경우:
  - 최종점수 또는 가중점수 100점 이상 → 10점
  - 100점 미만 → 0점

---

## 평가 평균 계산

```text
평가 평균 점수 = 전체 시험 평균 ÷ 100 × 20
```

- 실제 점수가 있는 시험만 계산합니다.
- `-` 또는 빈칸은 미응시/미진행으로 보고 제외될 수 있습니다.

---

## 출결 계산

```text
출결 점수 = 20 - 결석 횟수 - floor(지각 횟수 ÷ 3)
```

| 항목 | 기준 |
|---|---|
| 결석 | 1회당 -1점 |
| 지각 | 3회당 -1점 |

하루 출결은 아래 3개를 각각 확인합니다.

- 오전 출석
- 중간 출석
- 퇴실 출석

예를 들어 평일 5일이면 총 15회 출결을 확인합니다.

```text
5일 × 하루 3회 = 총 15회
```

## 주의사항

- 출석 시간 기준은 기수마다 다를 수 있으므로 사용 전 반드시 확인해 주세요.
- 중간 출석은 시트에 표시된 `출석 / 지각 / 결석` 값을 기준으로 계산합니다.
- `-` 값은 기본적으로 결석으로 처리합니다.
- 모든 출결이 계속 `-`인 사람은 운영자, 이탈자, 테스트 계정일 수 있으므로 확인이 필요합니다.
- 메모가 있는 출결이나 특이사항은 원본 시트에서 별도 확인해 주세요.
- 최종 반영 전에는 반드시 원본 엑셀과 계산 결과를 대조해 주세요.
